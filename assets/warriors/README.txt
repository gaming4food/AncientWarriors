Warrior artwork. Filenames are keyed by warrior id:
  Base heroes: w<id>.png   (w0.png = Leonidas ... w19.png = Sun Tzu)
  Mythics:     m<id>.png   (m100 Gilgamesh, m101 Beowulf, m102 Hecate, m103 Sun Wukong, m104 Hercules, m105 Ra)
Transparent-background PNGs. Any missing file falls back to the procedural figure.
Add an id to SPRITE_IDS in index.html when you add a new file.
